Project Overview: DeepStream License Plate Recognition Pipeline

1. System and Environment

Camera / RTSP device:
- Jetson Nano with a ZED camera.
- 1920x1080, 30 FPS H.264 RTSP/TCP stream.
- Current consumer URL: rtsp://192.168.0.126:8554/mystream.
- The native ZED service publishes its single upstream session at
  rtsp://127.0.0.1:8555/zed_stream. The existing MediaMTX service redistributes
  it on port 8554 so DeepStream and other clients can reconnect independently.
- The Nano uses the pinned Stereolabs ZED GStreamer plugin and a native RTSP
  service. It captures the left image with depth disabled, converts through
  the VIC, and encodes with NVENC without a Python/NumPy frame-copy loop.
- `/home/coen/stream.py` remains installed as the rollback implementation.

Inference device:
- NVIDIA Jetson AGX Xavier 16 GB.
- JetPack 5.1.6, DeepStream 6.3, TensorRT 8.5, CUDA 11.4.
- Python 3.8 with DeepStream Python bindings (pyds).
- RapidOCR 1.4.4 using ONNX Runtime 1.19.2.

Cloud logging:
- Confirmed plates are posted to the existing Convex uplink.
- The payload includes carPlate, fileTitle and direction.

2. AI Pipeline

Pipeline:
RTSP -> H.264 decode -> nvstreammux -> YOLO -> NvDCF tracker ->
LPDNet -> RGBA converter -> OSD -> nv3dsink

A. YOLO primary detector
- DeepStream component ID: 1.
- Uses the existing YOLO 640x640 FP16 TensorRT engine and custom parser.
- Runs on every input frame (`interval=0`). No detector input resolution or
  confidence threshold is reduced.

B. NvDCF tracker
- Runs at 640x384 using the existing performance configuration.
- Assigns stable vehicle IDs before LPDNet.
- Secondary plate detections use their tracked parent vehicle ID for OCR state.

C. LPDNet secondary detector
- DeepStream component ID: 2.
- Locates plates inside COCO car (class 2) and truck (class 7) objects.
- Uses the existing INT8 TensorRT engine at 3x480x640.

D. RapidOCR
- Recognition only; LPDNet already supplies the plate crop.
- Runs on one bounded background worker so OCR cannot stall the GStreamer pad
  probe or accumulate an unbounded backlog.
- ONNX Runtime uses four intra-op threads and one inter-op thread. On a saved
  plate crop this was faster than the default while leaving CPU capacity for
  GStreamer and DeepStream.
- GPU video memory is mapped only when an unconfirmed plate is actually due for
  OCR, rather than once on every frame.
- At most one OCR job can be pending for a tracked plate.
- OCR stops for a track as soon as its plate is confirmed.
- A plate requires three identical reads at confidence >= 0.85.
- The 0.15 second per-track throttle is unchanged.

3. Important Runtime Files

new.py:
- Builds and runs the complete plate-only pipeline.
- Reads DeepStream object metadata and queues plate crops for RapidOCR.
- Saves confirmed plate crops and posts the existing Convex payload outside the
  streaming thread.
- Preloads libgomp before OpenCV/RapidOCR so NvDCF can initialize reliably.

config_infer_yolo26.txt:
- YOLO PGIE configuration and custom parser settings.
- `interval=0` runs the primary detector on every source frame.

lpd_DetectNet2_us.txt:
- Existing LPDNet SGIE and INT8 engine configuration.

config_tracker_NvDCF_perf.yml:
- Existing NvDCF performance tracker configuration.

~/xavier_received_images/:
- Confirmed license plate crops.

4. Runtime Behavior

- Start command: DISPLAY=:0 python3 new.py
- Start the Nano RTSP stream before starting new.py on the AGX.
- Configuration paths resolve relative to new.py.
- The no-frame watchdog stops the pipeline after 15 seconds without input.
- Plate and object state expires 30 seconds after a track disappears.
- Image writes and Convex requests run outside the streaming thread.
- Ctrl+C transitions the pipeline to NULL and stops the OCR worker cleanly.

5. Scope

- Vehicle make/model recognition is not part of this pipeline.
- The NZ-50 classifier, manifest, training/export tools and runtime event log
  interface have been removed.
- No frontend or database changes are required.
- Do not commit ONNX files, TensorRT engines, model checkpoints or runtime
  plate images.
