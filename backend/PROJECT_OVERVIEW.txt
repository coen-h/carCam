Project Overview: DeepStream License Plate Recognition Pipeline
1. System & Environment Specifications
Hardware / Edge Device: NVIDIA Jetson Xavier (inferred via ~/xavier_received_images path).

JetPack 5.1.6, DeepStream 6.3, TensorRT 8.5.2, Python 3.8, and a 16 GB AGX Xavier in MAXN.

Core Frameworks: NVIDIA DeepStream SDK, GStreamer, TensorRT, ONNX Runtime.

Language & Bindings: Python 3 utilizing DeepStream Python Bindings (pyds).

Video Source: ZED Camera via RTSP TCP stream (rtsp://192.168.0.137:8554/zed_stream).

Cloud / Database Backend: Convex Serverless Backend (https://lovable-cat-739.convex.site/uplink).

2. AI Model Architecture
The project utilizes a 3-stage AI pipeline for detection, localization, and text recognition.

A. Primary Detector (PGIE): Custom YOLO
Model File: yolo26s.onnx (compiled to FP16 TensorRT Engine).

Function: General object detection (identifies Cars, Trucks, People, etc.).

Classes: 80 COCO Classes.

DeepStream Unique ID: 1

Custom Parser: Uses libnvdsinfer_custom_impl_Yolo.so to parse YOLO bounding boxes.

B. Secondary Detector (SGIE): NVIDIA LPDNet
Model File: LPDNet_usa_pruned_tao5.onnx (compiled to INT8 TensorRT Engine with calibration file).

Function: License Plate Detection/Localization.

Targeting: Only operates on bounding boxes generated by the PGIE for Cars (Class 2) and Trucks (Class 7).

DeepStream Unique ID: 2

C. Optical Character Recognition (OCR): RapidOCR
Library: rapidocr_onnxruntime

Function: Extracts text from the license plate crops provided by LPDNet.

Execution: Runs dynamically in the Python script via a GStreamer pad probe, rather than strictly as a DeepStream nvinfer element.

3. Important Files & File Structure
main.py (or equivalent Python script name): The core application runner. It constructs the GStreamer pipeline, attaches the buffer probe for metadata parsing, handles RapidOCR execution, and manages asynchronous HTTP requests to Convex.

config_infer_yolo26.txt: The configuration file for the Primary GIE (YOLO). Defines network mode (FP16), custom parsing library, batch size, and label paths.

lpd_DetectNet2_us.txt: The configuration file for the Secondary GIE (LPDNet). Defines the INT8 calibration, input dimensions (480x640), operation on specific PGIE classes (2 and 7), and cluster modes.

config_tracker_NvDCF_perf.yml: The low-level configuration for the nvtracker element. Uses the NvDCF (NVIDIA Data Association Tracker) to assign persistent IDs across frames.

~/xavier_received_images/: Local directory where cropped license plate images are saved upon confirmed reads.

4. Core Logic & Workflow
Pipeline Flow:
RTSP Source -> H264 Decode -> StreamMux -> YOLO (PGIE) -> NvTracker -> LPDNet (SGIE) -> Video Convert -> OSD (On-Screen Display) -> 3D Sink

Metadata Extraction & OCR Logic:

Buffer Probe: A probe is attached to the osd sink pad to intercept frame metadata (pyds.NvDsBatchMeta).

Object Filtering: The code filters for objects based on component ID. If the component ID is 1, it logs the physical vehicle/object. If the component ID is 2, it handles it as a license plate.

OCR Throttling: To prevent CPU/GPU bottlenecking, RapidOCR is throttled per unique vehicle tracker ID (max 1 OCR pass roughly every 0.15 seconds).

Plate Confirmation Protocol: * OCR results must meet a minimum length (4 characters) and confidence threshold (85%).

A specific plate text must be read identically 3 times (PLATE_CONFIRM_COUNT) on the same tracked object before it is considered "confirmed."

Cloud Logging: Once confirmed, the cropped image is saved to the local disk, and a background thread (_log_plate_async) fires an HTTP POST request to the Convex webhook with the plate text and filename. A cooldown (PLATE_LOG_COOLDOWN of 15 seconds) prevents spamming the server with the same plate.

5. Agent / Developer Notes
Custom YOLO Implementations: Ensure the libnvdsinfer_custom_impl_Yolo.so file remains compiled for the exact DeepStream version on the Xavier to prevent segfaults during pipeline initialization.

Threading: Webhook requests and image saving are properly offloaded to threading.Thread to prevent blocking the GStreamer buffer probe, which would otherwise stall the video feed.

Watchdog: The Python script includes a watchdog timer (make_watchdog) that will safely terminate the application if no frames are received from the RTSP stream for 15 seconds.
